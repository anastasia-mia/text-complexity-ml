This repository is part of my master's diploma project ***"System for Predicting English Text Complexity"***. The system provides automatic prediction of English text complexity according to the CEFR scale (A1–C2) based on a combination of linguistic, statistical, and readability metrics using machine learning methods.The system provides automatic prediction of English text complexity according to the CEFR scale (A1–C2) based on a combination of linguistic, statistical, and readability metrics using machine learning methods.

## Objectives 
- Analyze linguistic factors influencing text complexity  
- Extract lexical, syntactic, morphological, semantic, and readability metrics  
- Build and evaluate a machine learning model for CEFR classification  
- Implement a REST API for automated text analysis  
- Store and analyze prediction statistics

## Scientific Contribution
It was implemented a feature-based approach to CEFR-level prediction using a comprehensive set of linguistic metrics. A Random Forest model was used to analyze non-linear linguistic data.
